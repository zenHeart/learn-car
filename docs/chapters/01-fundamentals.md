# 第 1 章 汽车电子电气架构基础

> 能力目标：car-fundamentals — 用一张图描述汽车 E/E 架构中的域控制器、总线、传感器与执行器的关系，并区分动力域、底盘域、车身域、ADAS 域和座舱域的边界。

## 1.1 为什么需要先讲 E/E 架构

如果你只把汽车当成"四个轮子加一个发动机"，那你会在接触 CAN 总线、域控制器、HUD、HMI 时全部迷路。汽车电子电气架构（Electrical/Electronic Architecture，简称 E/E 架构）是回答"车上每一个电气部件是谁在管、谁在通信、谁负责供电"的总图。学完车机、ADAS、电动化三块之前，必须先把这张图记住，否则后面任何一个章节对你都只是孤立的术语堆。

2026 年主流的整车 E/E 架构正在从"分布式 ECU + 多总线"演进到"中央计算 + 区域控制器（zonal controller）"，但 L1 学习阶段先用经典五域模型建立直觉，再过渡到 zonal 模型。

## 1.2 五域模型

经典五域把整车控制器分成：

1. **动力域（Powertrain）**：发动机 ECU、变速箱 TCU、电机控制器 MCU、电池管理 BMS。这一域的特点是实时性极强（控制周期 1–10 ms）、功能安全等级最高（ASIL D），总线以 CAN/CAN FD 为主，正在向车载以太网迁移。
2. **底盘域（Chassis）**：电子稳定控制 ESC、电动助力转向 EPS、线控制动 iBooster、空气悬挂。控制周期与动力域类似，安全性同样 ASIL D，也是底盘域线控的最终落点。
3. **车身域（Body）**：车身控制 BCM、车门模块 DCM、车窗/天窗/灯光、雨量光线传感器。控制周期宽（10–100 ms），实时性弱，但节点数量多，多用低速 CAN 与 LIN 总线降低成本。
5. **ADAS 域**：前视摄像头、前/角毫米波雷达、激光雷达、定位 IMU、ADAS 中央控制器（域控）。带宽需求大（摄像头原始数据 ≥1 Gbps），所以这一域内大量使用车载以太网（100/1000BASE-T1）与 SerDes（如 GMSL、FPD link）。
6. **座舱域（Cockpit / Infotainment）**：数字仪表 IVI、HMI、HUD、语音助手、导航。座舱域既要渲染 HMI 又要保证仪表实时，所以行业常见做法是用 Hypervisor 同时跑 QNX（仪表）与 Android Automotive（应用）。

这五域之间用网关控制器（Central Gateway）做消息路由、协议转换与安全隔离。网关同时承担 OTA 主控、网络管理（如 AUTOSAR NM）与诊断路由（UDS over CAN DoIP）三种职责，是整车网络的核心。

## 1.3 传感器、执行器与线束

传感器是把物理量转成电信号的部件。常见的有：

- 温度/压力/位置：NTC、压阻、霍尔；
- 转速/扭矩：旋转变压器、磁阻；
- 视觉：前视 8MP 摄像头、环视 4×2MP；
- 雷达：77 GHz 毫米波、4D 成像雷达；
- 激光雷达：905 nm / 1550 nm 半固态/固态。

执行器把电信号变回物理动作：喷油器、节气门、线控转向电机、刹车卡钳电机、空调鼓风机、屏幕背光等。传感器和执行器都不直接连到云端——它们挂在所属域的 ECU 上，由 ECU 做本地闭环控制，再把状态/事件通过总线广播。

线束（harness）是这一切的物理承载。早期的分布式架构一辆车可能有 3–5 km 线束、3000+ 接插件；zonal 架构通过把线束按区域收敛到区域控制器（zonal），可把线束缩短 30–50%、质量减少 20–30%。

## 1.4 域控制器与"中央计算+区域"过渡

经典五域正在被中央计算单元（如高通 SA8295、英伟达 Orin、地平线 J6）与 4–6 个区域控制器（zonal control module）的形态取代。区域控制器按车的物理区域（前、左、右、后等）聚合输入输出，上行连到中央计算，下行就近接入传感器与执行器。

这一变化的工程意义：

- 整车线束从"点对点"变成"星形"；
- 软件 OTA 不再是逐 ECU 升级，而是中央计算单元的整体版本升级；
- 算力集中后，AI 推理（感知、语音、HMI）可以从单 ECU 加速器变成全车共享的算力池。

L1 阶段先记五域，再记 zonal，是阅读 2026 年 OEM 招聘 JD 时不被淘汰的最低门槛。

## 1.6 工程实践：典型网关芯片

做 E/E 架构离不开网关芯片。市面上典型选择有：

- **NXP S32G**：车规级 + ASIL D，集成 CAN FD、LIN、车载以太网与 Cortex-A53；
- **TI TDA4VM**：面向 ADAS 中央域控，含 C7x DSP 与 MMA 阵列；
- **瑞萨 R-Car**：座舱域标杆，从 R-Car H3 到 R-Car M3 多代演进；
- **地平线 J5/J6**：国产 ADAS 域控主流，搭载 BPU 神经网络加速器；
- **华为 MDC 平台**：覆盖 MDC 210 至 MDC 810 多档算力。

选网关芯片时要看三件事：内核架构（Cortex-A/R/M 组合）、总线接口数量（CAN FD 通道数、以太网端口数与速率）、软件生态（AUTOSAR Classic/Adaptive 支持、Linux/QNX BSP 成熟度）。

## 1.7 自检题答案

1. 动力域管发动机与变速箱，底盘域管制动/转向/悬挂；二者在功能安全上同属 ASIL D，但控制对象不同——动力域扭矩闭环，底盘域横摆/纵向/垂向耦合控制。
2. 因为仪表盘是 ASIL B 安全实时域（不允许卡顿、不允许重启），而座舱主屏是 QM 应用域（允许 OTA 升级、应用崩溃）。两者同 SoC 不同 OS，避免座舱应用 bug 影响仪表安全显示。
3. 区域控制器按物理区域就近接入传感器与执行器，原本需要从传感器一路拉到中央 ECU 的长线束被缩短为"区域到中央"中长线束，长度与质量显著下降。
